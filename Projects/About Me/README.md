# Hendrik Tandiono: About Me

A responsive single-page portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Local preview

Serve this directory with any static HTTP server, then open its root URL. Opening `index.html` directly also works, but clipboard access may be limited by the browser.

## Public deployment

The repository workflow publishes this directory at `/Projects/about-me/` while preserving the repository landing page at the GitHub Pages root.
