01 / About us

We built Eventure for both sides of the event.

Most event platforms focus on the booking screen. We looked at what happens before the booking and what organizers deal with afterward.

Attendees need a quick way to find the right event and follow their order. Organizers need practical tools for tickets, payments, attendees, and reporting. Eventure puts those jobs in one place.

03 / Checkout

A booking should not fall apart when plans change.

A single order can affect seat availability, vouchers, coupons, and reward points. Eventure updates them together. If an order expires, is cancelled, or is rejected, the reserved items are returned together.

Attendees upload payment proof. Organizers review it before approving or rejecting the order.

04 / Behind the platform

Technology chosen for a busy event workflow.

Eventure uses TypeScript from the web interface through to the API. PostgreSQL stores orders, tickets, rewards, and attendee records, with Prisma keeping those relationships consistent.

Web
Next.js, React, and TypeScript
API
Express with role-based access
Data
PostgreSQL managed through Prisma
Delivery
Vercel, Supabase, and transactional email
